# Security policy

Security fixes are provided for the latest published version of Morphant.
Users should upgrade to that version before reporting an issue that may already
be fixed.

## Reporting a vulnerability

Please do not disclose a vulnerability in a public issue. Use
[GitHub private vulnerability reporting](https://github.com/strangeman375/Morphant/security/advisories/new)
and include:

- the affected Morphant version;
- the impact and conditions required to reproduce it;
- a minimal reproduction or proof of concept, when possible;
- any suggested mitigation.

If private reporting is unavailable, open an issue containing no vulnerability
details and ask the maintainer for a private contact channel.
